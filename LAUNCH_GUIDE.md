## 🎯 Quick Start (Choose Your Path)

### Path A: Super Fast ⚡ (2 minutes)

```bash
# Just run this:
setup.bat
```

Then open two terminals:

```bash
# Terminal 1:
cd backend && npm.cmd start

# Terminal 2:
cd frontend && npm.cmd start
```

### Path B: Fastest 🚀 (30 seconds)

```bash
# Just double-click:
start-dev.bat
```

⚠️ Makes sure you're in the project root directory first!

### Path C: Manual Setup

```bash
# Backend
cd backend
npm.cmd install
npm.cmd start
→ Runs on http://localhost:5000

# Frontend (new terminal)
cd frontend
npm.cmd install
npm.cmd start
→ Opens http://localhost:3000
```

## 🆘 If You Need Help

### Quick Troubleshooting

1. **Camera not working?**
   - Check browser permissions
   - Use HTTPS or localhost
   - Refresh browser

2. **Port already in use?**
   - Change port in `.env` files
   - Or stop other applications

3. **API not connecting?**
   - Verify backend is running
   - Check API URL in `.env`
   - Look at browser console (F12)

4. **Styles not loading?**
   - Refresh with Ctrl+Shift+R
   - Clear browser cache
   - Restart npm servers
